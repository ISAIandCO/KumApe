# Конфиденциальность KumApe

KumApe работает локально в Firefox и не содержит аналитики, телеметрии, рекламы или собственного сервера.

Расширение хранит локально адреса Web UI и REST API KUMA, а также выбранный идентификатор storage cluster. API-токен сохраняется только в `browser.storage.session` и удаляется после завершения сессии Firefox. Логин, пароль, Cookie и XSRF-токены KUMA расширение не сохраняет и не журналирует.

Содержимое открытого события читается из вкладки KUMA и показывается в popup. Поиск связанных событий отправляется только на настроенный REST API KUMA. Данные события не отправляются внешним TI-провайдерам автоматически: переход в Kaspersky OpenTIP или VirusTotal происходит лишь после явного нажатия соответствующей кнопки.

Разрешение на доступ запрашивается для конкретных origin Web UI и REST API, выбранных пользователем. Переход к внешнему провайдеру открывает обычную вкладку и не дает KumApe доступ к её содержимому.
