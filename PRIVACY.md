# Конфиденциальность KumApe

KumApe работает локально в Firefox и не содержит аналитики, телеметрии, рекламы или собственного сервера.

Расширение хранит локально адреса Web UI и REST API KUMA, а также выбранный идентификатор storage cluster. Токен KUMA и ключи IOC-провайдеров сохраняются в `browser.storage.local` в профиле Firefox, переживают перезапуск и обновление расширения, не синхронизируются через Firefox Sync и удаляются кнопками в настройках. Дополнительное шифрование ключей расширение не выполняет. Логин, пароль, Cookie и XSRF-токены KUMA расширение не сохраняет и не журналирует.

Содержимое открытого события читается из вкладки KUMA и показывается в popup. Поиск связанных событий отправляется только на настроенный REST API KUMA. При явном выборе «Открыть в новой вкладке» или «Открыть в KUMA» SQL-фильтр и относительный период передаются в URI Threat Hunting, поэтому они могут сохраниться в истории браузера и KUMA. Данные события не отправляются внешним TI-провайдерам автоматически: проверка через API или переход в Kaspersky OpenTIP, VirusTotal либо AbuseIPDB происходит лишь после явного нажатия соответствующей кнопки. Провайдер получает выбранный IOC и свой API-ключ при API-проверке, но не полный JSON события, Raw или токен KUMA.

Разрешение на доступ запрашивается для конкретных origin Web UI и REST API, выбранных пользователем. Для API-проверок дополнительно запрашивается доступ к выбранному провайдеру и разрешение Firefox на передачу данных. Переход к отчёту открывает обычную вкладку. Скрипт меню автоматически работает только на настроенном узле KUMA.
