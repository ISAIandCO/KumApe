# Changelog

## 0.3.14

- Общий контроллер AI подключён ко всем чатам; проверяются адрес отправки, актуальность предпросмотра и запрет повторной отправки.
- Хранение снимков графа использует общую проверку схемы и лимиты.
- Длинные AI-вложения сохраняются в рамках бюджета 2 MiB без обрезки по лимитам карточек расследования.

- Подключены общие графы, пошаговый поиск, страница расследований и AI-диалог ApeShareCore 1.2.
- Расследования и чаты используют общую модель и stores workspaces/aiChats. Старые тестовые расследования из схемы v1 автоматически не переносятся.
- Отмена графа прерывает сетевой запрос; снимок восстанавливается без повторной загрузки. SQL, API и mappings KUMA остаются в адаптере.
