Подключение к Kaspersky KUMA 4.6

Токен хранится только в памяти текущей сессии Firefox и удаляется при закрытии браузера. Логин и пароль KUMA расширение не запрашивает.

Проверка подключения

Сначала сохраните настройки.

Если API использует внутренний сертификат, сначала откройте его адрес, подтвердите доверие в Firefox и затем повторите получение кластеров. Ответ 401 в открытой вкладке допустим: токен передаётся только из расширения.

Только чтение

KumApe разрешает лишь проверку сессии, получение кластеров, поиск событий и чтение ресурса правила корреляции. Изменяющие запросы заблокированы в background-слое.
